# 贵州五日游行程

## 一、行程概览

**时间：5天4晚**

**到达：**

* D1 16:40 抵达贵阳北站

**返程：**

* D5 17:50 贵阳北站出发

**行李配置：**

* 1个大背包：衣物、洗漱用品等
* 1个随身小包：手机、身份证、充电宝、雨具、水等

**核心路线：**

贵阳 → 黄果树瀑布 → 荔波小七孔 → 大七孔 → 西江千户苗寨 → 贵阳

---

# 二、酒店安排

| 日期 | 住宿区域           | 建议            |
| -- | -------------- | ------------- |
| D1 | 贵阳北站西广场附近      | 与D2同一家酒店      |
| D2 | 贵阳北站西广场附近      | 连住第二晚         |
| D3 | 荔波小七孔东门 / 梦柳小镇 | 步行前往景区方便      |
| D4 | 西江千户苗寨景区内      | 1号风雨桥 / 游方街附近 |
| D5 | 不住宿            | 17:50贵阳北返程    |

## 酒店位置要求

### 贵阳酒店

搜索范围：

> 贵阳北站西广场 / 贵阳北站地铁站

建议：

* 距离贵阳北站步行10分钟以内
* D1、D2连续住两晚
* 不需要住甲秀楼、大十字等市中心区域

### 荔波酒店

搜索范围：

> 荔波小七孔东门 / 梦柳小镇

建议：

* 距离小七孔东门步行5～15分钟
* 支持提前寄存行李
* 有荔波站接送更好

**不建议住荔波县城。**

### 西江酒店

搜索范围：

> 西江千户苗寨景区内 / 1号风雨桥 / 游方街

建议：

* 景区内
* 靠近1号风雨桥
* 靠近主街和观光车站
* 最好提供景区内接送

**不建议住山顶或需要爬大量台阶的半山民宿。**

# D2｜黄果树瀑布

## 行李

### 大背包

**留在贵阳酒店房间。**

因为D2晚上继续住同一家酒店。

### 小包

随身携带：

* 手机
* 身份证
* 充电宝
* 雨具
* 水
* 防晒
* 少量纸巾

---

## 时间安排

| 时间          | 行程          |
| ----------- | ----------- |
| 07:00       | 起床          |
| 07:20       | 早餐          |
| 07:50       | 整理随身物品      |
| 08:00左右     | 前往贵阳北西广场乘车点 |
| 08:20左右     | 贵阳 → 黄果树    |
| 10:00左右     | 到达黄果树       |
| 10:00～17:00 | 黄果树景区       |
| 17:00左右     | 返回贵阳        |
| 19:00～20:00 | 抵达贵阳        |
| 晚上          | 吃饭、休息       |

---

## 黄果树游览顺序

推荐：

**陡坡塘 → 天星桥 → 黄果树大瀑布**

### ① 陡坡塘

预计：

**40分钟～1小时**

主要看瀑布。

---

### ② 天星桥

预计：

**2～3小时**

当天时间紧张时，不需要每个小景点全部停留。

---

### ③ 黄果树大瀑布

预计：

**2小时左右**

黄果树大瀑布是当天重点，至少留出充足时间。

如果水帘洞当天开放并成功预约，可以进入水帘洞。

---

## D2晚上

回酒店后：

* 洗澡
* 吃饭
* 整理D3行李
* 所有物品装入大背包

D3早上退房后不再返回贵阳酒店。

---

# D3｜贵阳 → 荔波 → 小七孔

## 核心原则

**到荔波以后，先去酒店放大包，再进入小七孔。**

路线：

> 贵阳北 → 荔波站 → 小七孔东门酒店 → 放大包 → 小七孔景区

不要背着大包游览小七孔。

---

## 上午

建议购买：

**贵阳北 → 荔波**

优先选择：

> 07:00左右出发的早班动车

参考时间：

| 时间          | 行程       |
| ----------- | -------- |
| 06:00       | 起床       |
| 06:20       | 退房       |
| 06:30左右     | 到贵阳北站    |
| 07:00左右     | 贵阳北 → 荔波 |
| 08:10～08:30 | 抵达荔波站    |

---

# D3抵达荔波后的具体流程

## 第一步：荔波站 → 酒店

到站以后：

**不要直接进景区。**

直接前往：

> 小七孔东门 / 梦柳小镇酒店

交通：

* 打车
* 景区接驳
* 酒店接站

预计：

**15～20分钟**

---

## 第二步：酒店放大包

预计：

**08:40～09:00到酒店**

即使酒店暂时不能办理入住，也直接：

> 前台寄存大背包

### 大背包留酒店

里面放：

* 衣服
* 洗漱用品
* 第二天用品
* 备用鞋
* 其他非必要物品

### 小包带进景区

携带：

* 手机
* 身份证
* 充电宝
* 水
* 雨伞 / 雨衣
* 防晒
* 纸巾
* 少量零食

建议准备一个小防水袋放手机、充电宝。

---

# D3｜09:15～17:30 小七孔

## 推荐路线

**小七孔东门进入**

↓

**坐观光车前往西门方向**

↓

从西向东游览

↓

**最后回到东门**

↓

步行返回酒店

---

## 游览顺序

推荐：

1. 卧龙潭
2. 鸳鸯湖
3. 翠谷瀑布
4. 水上森林
5. 六十八级跌水瀑布
6. 拉雅瀑布
7. 小七孔古桥

预计游玩：

**6～8小时**

小七孔是这次贵州行程中的重点景区，不压缩成半日游。

---

## D3晚上

| 时间          | 安排         |
| ----------- | ---------- |
| 17:30～18:00 | 小七孔东门出景区   |
| 18:00～18:30 | 回酒店        |
| 18:30       | 办理入住 / 取大包 |
| 19:00       | 梦柳小镇吃饭     |
| 21:30左右     | 回酒店休息      |

当天晚上不去荔波县城。

---

# D4｜大七孔 → 西江千户苗寨

## 上午退房

起床后收拾大包。

然后：

> 办理退房 → 大包寄存在酒店前台 → 只带小包去大七孔

不要背着大包游览大七孔。

---

## 08:30～11:30 大七孔

### 行李

* 大包：酒店前台
* 小包：随身

### 游览

预计：

**2～3小时**

D3已经完整游览小七孔，因此D4上午安排大七孔，不重复小七孔。

---

## 11:30 返回酒店

流程：

**大七孔 → 酒店 → 取大包 → 午饭**

参考：

| 时间          | 安排       |
| ----------- | -------- |
| 08:00       | 早餐、退房    |
| 08:30       | 前往大七孔    |
| 08:30～11:30 | 大七孔      |
| 11:30～12:00 | 返回酒店     |
| 12:00       | 取大包      |
| 12:00～13:00 | 午饭       |
| 13:00～14:00 | 休息、前往乘车点 |

**08:00左右**

# D5下午｜贵阳北

预计：

**14:00左右抵达贵阳北**

距离17:50返程仍有约3～4小时。

下午不再前往甲秀楼、青岩古镇等较远景点。

可以安排：

* 贵阳北附近吃饭

* 买特产
* 整理行李
* 提前进站

**16:30～16:50进入贵阳北站**

**17:50正式返程**
